A single hero bowl of ramen, drawn from scratch with Python and Pillow. Golden
broth with a glossy sheen and chili-oil beads, a tangle of springy noodles, two
jammy soft-boiled eggs with orange yolks, seared chashu, a pink narutomaki
swirl, nori, scallions and sesame, with chopsticks resting on the rim and faint
steam rising. One dish, no text.

## Run

```sh
python3 main.py
```

The script copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default
`/output`), verifies the copy with SHA-256, and prints the digest. It uses only
the Python standard library.
